# 模拟引擎与受控变速扩展

## 当前数据流

`静态盘面 → 旋转模型 angleAt(t) → 采样时间 → 曝光期间旋转副本加权累积 → 完整预览 → 固定位置裁剪`

`createPlate(material, geometry)` 在 Canvas 上生成一张固定纹理；按需缓存当前排布的有编号和无编号版本。多圈共享已投影的图层，调整一圈的位置只重算该圈。动作姿态只由盘面格号决定，不读取播放时间。绘制每个视频帧时只旋转完整纹理。局部观察窗直接裁剪本次已累积的结果，没有独立的源动作播放器。

- 54 个等距位置，18 帧动作重复 3 次，所有姿态以局部径向坐标排布。
- 盘面帧序为 `(-slot mod 18)`：顺时针旋转时，下一个进入顶部观察点的格子携带下一个动作姿态。反转物理转速自然反转帧序。
- 首版转速是恒定的，支持在运行中修改。转速编辑保存过去的运动历史，当前角度连续；相机采样率改变则会重新选择采样网格，显示的采样帧可能改变。
- 默认 33⅓ RPM、30 fps、1/1000 秒曝光，默认暂停。相机配置内切换连续旋转与相机采样，两种模式沿用同一物理时间。

## 时间、旋转与相机分离

引擎统一使用秒、带符号的 RPM 和不取模的弧度。只在 Canvas 绘制时取角度模数。三个接口分别承担不同职责：

- `Transport`：注入 wall time，管理播放、暂停、定位，不负责角度或画面。
- `RotationModel`：提供 `angleAt(t)`、`rpmAt(t)` 和区间总角行程 `angularTravel(start, end)`；渲染器依赖此接口。
- `SamplingSchedule`：提供采样序号与采样时间转换，不依赖盘面或旋转方式。

`RotationTimeline` 使用分段线性 RPM 并解析积分：

`angle(t) = startAngle + π/30 × (startRPM × Δt + acceleration × Δt²/2)`

`setSpeedAt(t, targetRPM, rampSeconds)` 支持瞬时切换与有限时长的线性加减速。首版 UI 使用 rampSeconds=0。历史定位后再编辑会保留更早的历史并重建之后的运动。这也保证跨越变速时刻的曝光查询到正确的旧角度，而不是用“当前 RPM × 全部时间”重算过去。

相机使用独立的 `FixedRateSchedule`：

`k = floor(t × fps)`；`sampleTime = k / fps`

一帧保持到下一采样时刻，不在两个相机帧之间插值。渲染循环以真实经过时间定位；屏幕性能不足时跳过过期显示帧，不减慢物理时间。高于屏幕刷新率的相机帧无法保证全部显示，可暂停逐帧检查。

## 曝光模型与精度

快门区间为 `[max(0, sampleTime − exposure), sampleTime]`，不读取未来姿态。曝光最长不超过一个相机周期。零时刻没有曝光前历史，显示初始盘面。

`exposureSamples()` 用中点积分取多个时间点，再通过 RotationModel 得到各自角度。`renderExposure()` 对完整静态纹理的这些旋转副本做等权、预乘透明度加法累积。它不是 CSS blur，也不修改盘面上任何动作帧。

单个姿态直接通过 Canvas 2D 绘制。多样本曝光在 WebGL 2 片元着色器中对预乘颜色和透明度求平均，最后量化到显示画布。没有可用 WebGL 2 上下文时，Canvas 2D 路径用 32 位整数缓冲累积相同的预乘量。两条路径都在显示色彩空间近似运动拖影。

积分次数取决于快门内的总角行程和画布大小，上限为 96。分段转速在变速点和过零点计算行程，往返运动都计入。达到上限时界面提示可能出现离散重影。

在默认 33⅓ RPM、30 fps 下，1/30 秒曝光期间跨越一整格；1/1000 秒则仅移动约 0.03 格。短曝光验证排布与采样，长曝光验证旋转拖影。

## 暂停搓碟

手势层使用 `@use-gesture/react` 处理拖动、触控、捕获与取消；将指针相对圆心的角度差转换为 `RotationTimeline.rotateBy()`。跨越 ±π 时按最短有符号角差累加；圆心设置死区，避免角度奇点造成跳动。只有暂停时启用，松手即停，播放中禁止手动搓碟。

搓碟定义为调整整张盘面的初始相位，不推进模拟时间、不模拟 DJ 惯性或手动角速度。相位参与所有 angleAt(t) 查询，包括连续旋转、相机和曝光累积，所以局部观察窗也同步改变。它会整体重新定位历史预览，保留原有转速轨迹。随后播放沿当前相位继续，变速不会重复加上相位；回到起点清除手动相位。

键盘可聚焦盘面，用左右方向键旋转 1°，Shift 加方向键旋转 10°。

## 恒定转速与 CD 驱动

恒速工作台在当前时间记录转速和方向。回退后点「回到起点」，以回退位置的带符号转速作为新时间线的起始值，控件和自动匹配采样率随之更新。

CD 驱动由 `CdRotation` 根据读取半径和线速度生成控制轨迹，可以选择理想跟随或限制加减速。相机按起始转速匹配后保持固定帧率。主面板与圆环详情使用同一对采样时刻之间的角位移，再乘各圈格数，得到各自的逐格匹配结果。

## 验证

`npm test` 使用 Node.js 24 的原生 TypeScript 执行能力，无额外测试依赖。

覆盖：默认逐格同步与正确帧序、18 帧循环接缝、2% 失配五秒漂移三格、相机帧保持、转速切换与反转的相位连续性、500→1000 RPM 曲线的解析积分、回退后编辑分支、曝光时间与权重、播放时钟与逐帧定位。

浏览器验证完整盘面、局部观察窗、逐帧、播放/暂停、实验预设、两种观察模式、反向与窄屏布局。部署继续使用 Cloudflare Workers Static Assets，无后端、无远程素材依赖。


## 观察界面

工作台并排显示盘面和局部观察窗。白框内部可以沿半径拖动，边缘调整宽高，侧栏可以直接输入观察半径。观察画面直接裁剪完整盘面的曝光结果。窄屏可横向滚动工作区，同时使用顶栏进入设计指南。

观察窗提供纵向 1:2、聚焦 1:1、标准 2:1（默认）、宽幅 3:1 四个预设，保持观察中心与垂直范围固定，改变水平视野。画布高度根据裁剪比例同步调整，避免拉伸；暂停或专注查看时切换也会重新绘制，不改变盘面相位和采样配置。


## 可配置素材与几何（第二阶段）

`PlateMaterial` 区分生成示例与图片快照；`PlateGeometry` 显式保存 slots / frames / repeats。原有 PLATE 常量只作为初始默认值，不再固定渲染与相机计算。配置提交前验证整数范围与 slots=frames×repeats；观察器、编号、自动匹配采样率、失配预设与动作周期均使用已应用配置。导入图片的这些参数属于声明，不改变原始图案的排布，也不自动验证其帧序。

图片通过本地 object URL 解码，使用 ImageBitmap 冻结像素，再以校准圆心与半径做统一缩放和平移。目标中心与旋转轴重合，X/Y 共用同一缩放因子，圆外像素裁去；矩形与偏心原图不被拉伸。原图预览也从同一冻结快照绘制，不让 APNG/WebP 等可能的动画源绕过静态盘面要求。替换和卸载时关闭 ImageBitmap、回收 URL，异步加载通过请求序号防止旧图片覆盖新选择。

原图点选通过 object-fit:contain 的留白与缩放映射回原始像素。校准与排布输入有独立草稿，只有通过校验且应用后才影响预览；应用时停止时钟并复位相位。观察半径仅控制固定观察窗的位置，不改变素材校准和旋转模型。

转臂示例按圆周位置烘焙编号与指针角度。正确的相邻指针跨接缝仍前进一步；错误接缝示例仅将最后一个姿态改为首帧，使接缝前跳步且首帧重复。预览仍只旋转整张静态纹理，没有单独更新编号或角色。测试覆盖 正向 01→02→…→12 与反向 01→12→…→02 的采样序列、错误接缝、几何约束、偏心圆等比归一化和非正方形预览的点选坐标换算。


## 多圆环静态合成

`RingLayer` 独立持有素材、排布、启用状态、源/目标圆环内外缘与相位。`createRingProjector()` 生成逆极坐标映射：目标点的归一化半径线性映射到源圆环，角度减去静态相位。它由渲染器与测试共同使用。输出缓冲区复用，避免逐像素分配对象。

`createCompositePlate()` 逐层构建静态纹理，以预乘透明度的双线性插值采样源像素，环缘做约一个像素的羽化；后绘制的圆环覆盖前面的圆环。辅助编号在目标圆环上生成，并应用相同相位，图片只标声明格号。所有处理都发生在素材/配置变化时，不读取播放时间。随后仍由原 RotationModel + SamplingSchedule + renderExposure 旋转、曝光和取样，观察窗直接裁剪同一个合成帧。

每圈使用独立、带唯一前缀的 PlateEditor。切换编辑圈或单/多盘模式时隐藏编辑器而不卸载，以保留校准、草稿与 ImageBitmap；删除某圈时才释放该圈拥有的图片。文件异步完成时通过最新回调与请求序号更新，防止旧回调覆盖后来修改的位置。当前不提供跨圈复制 ImageBitmap，避免多个编辑器错误共享销毁责任。

自动采样率只参考一个明确选定且启用的圆环；每圈用自身格数乘相邻两次采样间的净转数绝对值，第零帧按起始转速估算。值为 1 时为逐格同步，其他值标为非逐格匹配，不直接断言一定漂移；整数跨格也可能产生稳定但跳帧的混叠。对应动作周期按本圈自己的逐格匹配率计算，不用当前失配相机帧率冒充实际动作周期。

参考圈关闭或删除时回退到首个启用圈；全部隐藏时保留正的有效时间参数，并显示明确空状态。观察圈有独立目标，选中编辑圈不会暗中改变相机；“观察此圈”才定位，手动半径可以覆盖该目标并复位。

范围约束：最多 4 圈，目标内缘 20–82%、外缘不超过 98%、宽度至少 5%；源内外缘 0–100%、宽度至少 5%；相位 −360° 到 360°。默认示例三圈同为 54 格但有不同帧数，测试覆盖共同采样、动作周期、不同格数的分别匹配、源/目标半径映射、相位方向、非法范围及参考圈回退。

CD 驱动与恒速驱动使用相同的圆环合成结果。


## 圆环检查器界面整理

图层列表仅保留名称、目标范围、格数、启用状态以及观察/参考标记。当前圈的参数分为三个标签页：素材与循环（复用无重复标题的 PlateEditor）、位置映射（源图范围、盘面位置、相位）、采样检查（只读采样结果与同步参考操作）。源/目标半径分开成组，以范围条辅助理解百分比。名称、排序和删除收在管理区。

每圈的标签页与位置草稿独立保存。TabsContent 使用 forceMount，并以 inactive 状态隐藏，避免换页卸载素材拥有者而释放 ImageBitmap。当前圈以外的检查器也保持挂载；只有实际删除圆环才触发资源释放。此整理不修改合成、旋转或采样算法。
