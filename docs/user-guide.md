# Zoetrope 唱片实验室

用于模拟 Zoetrope 旋转动画唱片的纯前端项目。内置 54 个位置、18 帧动作重复三次的静态盘面，支持：

- 相机配置内可切换连续旋转与相机采样两种观察方式。
- 播放/暂停、上一/下一采样帧、回到起点。
- 1–78 RPM、正反转、自动匹配或手动采样率、曝光时间。
- 同步动画、失配漂移、曝光拖影实验预设。
- 观察窗与完整盘面并排展示，支持仅观察窗、仅盘片与双栏并排三种预览布局及纵向 1:2 / 聚焦 1:1 / 标准 2:1 / 宽幅 3:1 比例预设（悬停唱片取景框显示）。可拖拽边缘及右下角从中心对称调整视野宽高，播放时也能实时调整。支持盘面位置和动作帧编号、预览缩放。
- 暂停时拖拽搓碟（鼠标/触控），支持方向键微调；松手即停。

相机画面从同一张静态盘面旋转、采样和曝光累积计算，未单独播放角色动画。默认暂停；不使用页面频闪。

## 技术栈

- Vite + React + TypeScript
- Tailwind CSS 4（官方 Vite 插件，CSS-first 配置）
- shadcn/ui（Radix UI 交互基础）+ Lucide 图标
- React Router（声明式 BrowserRouter）
- @use-gesture/react（搓碟拖拽手势）
- Oxlint（沿用官方 Vite 模板）
- Cloudflare Workers Static Assets + Wrangler

## 本地开发

推荐 Node.js 24 LTS（搭建时使用 Node.js 24），使用 npm 管理依赖。

```bash
npm install
npm run dev
```

打开终端输出的本地地址。

```bash
npm test            # 同步、漂移、曝光与变速时间线测试（Node.js 24）
npm run lint        # 静态检查
npm run build       # TypeScript 检查并构建到 dist/
npm run preview     # 使用 Vite 预览构建产物
npm run preview:cf  # 构建后使用本地 Workers 环境预览
```

## 部署到 Cloudflare Workers

通过 Workers Static Assets 托管 `dist/`，不需要编写 Worker 服务端脚本。`wrangler.jsonc` 已配置 `not_found_handling: "single-page-application"`，前端路由直接访问和刷新会回退到 `index.html`。

Cloudflare Workers 已连接本仓库，`main` 分支有变更时会自动触发构建与部署，日常更新只需推送代码，无需手动操作。

以下命令仅用于备用手动部署，运行前先登录 Cloudflare：

```bash
npx wrangler login
npm run deploy
```

`deploy` 会先执行构建，再使用 Wrangler 发布。Worker 名称默认为 `zoetrope-animated-demo`，可在 `wrangler.jsonc` 中修改。部署地址以 Wrangler 输出为准。

Cloudflare Workers Builds 的仓库构建配置：

- 构建命令：`npm run build`
- 部署命令：`npx wrangler deploy`
- 项目根目录：当前目录

## 模拟边界与后续扩展

当前模拟固定帧率相机、全局快门和近似运动曝光；不模拟滚动快门、自动曝光、实体照明。曝光使用最多 96 个时间样本进行像素平均，达到上限会提示精度限制；高采样率受屏幕刷新能力限制，可逐帧检查。

运动模型与相机独立，支持解析积分的分段 RPM、线性加减速及 CD 受控变速。详见 [模拟引擎与受控变速扩展](simulation-design.md)。

## UI 组件与主题

公共组件位于 `src/components/ui/`，已引入 Button、Badge、Slider、Select、Switch、Tabs、Accordion、Tooltip、Input、Label 和 Separator。配置见 `components.json`，`@/` 指向 `src/`。后续可通过 `npx shadcn@latest add <组件名>` 扩展。

整体采用 Cobalt / Slate 主题：冷灰背景、钴蓝主色，Canvas 盘面同步采用蓝色配色。`src/index.css` 使用 shadcn 语义变量（`--background`、`--primary`、`--muted`、`--border` 等），通过 `@theme inline` 映射至 Tailwind；在 `:root` 与 `.dark` 中集中调整浅色和深色样式。

页头可切换浅色 / 深色，首次访问跟随系统，手动选择保存在本地。页面加载前应用主题，避免颜色闪烁；存储不可用时仍可切换。

界面采用 PC 全窗口工作台：固定顶栏、左侧配置栏、中间盘面主舞台、右侧同源观察监视器和底部播放控制与采样状态栏。配置栏独立滚动，包含运动、相机、检查工具、实验预设、素材上传与校准、多圆环编辑；配置直接展开。预览始终可见，支持联合观察、仅观察窗、仅盘片。联合观察以左侧盘面为主舞台，右侧监视器用于固定位置的局部动作检查，两个画面来自同一次曝光积分。针对 1024px 及以上桌面窗口优化，侧栏按窗口宽度使用 280 / 300 / 320px，不提供手机堆叠布局。画面随可用宽高缩放，模拟时钟、采样和曝光计算沿用原有模型。


## 自己的盘面图片

在首页“盘面素材与校准”中选择 PNG、JPEG 或 WebP（不超过 20 MB、2400 万像素）。图片仅在浏览器本地解码，导入时冻结成不可变像素快照；即使源文件包含动画，也只模拟这一张静态画面。刷新页面后需重新选择文件。

1. 在原图上点击圆心，再切换“设置半径”点击外缘；也可填写原图像素坐标。
2. 点击“应用校准”，选定圆形区域会等比对齐旋转轴，圆外内容被裁去。
3. 输入圆周格数、独立帧数和重复次数，满足“格数 = 帧数 × 重复次数”后应用。
4. 返回预览，拖拽唱片上的取景框边缘调整宽高；取景中心保持固定。悬停取景框选择比例预设，再用自动匹配或手动采样检查。多圆环模式可用“观察此圈”定位到对应圆环。

导入图片的排布参数只是对既有图案的声明，不会重排图片、补帧或自动识别真实动作。应用素材、校准和排布配置时会暂停并回到起点；参数草稿未应用前不改变模拟器。

## 方向与接缝示例

- **弹跳**：54 格、18 帧 × 3。
- **转臂与计数**：48 格、12 帧 × 4；默认顺时针时编号 01→12，反向旋转时递减，末帧到首帧的转臂连续。
- **错误接缝对照**：故意把最后一帧替换为首帧，产生跳步及首帧重复停顿，说明“格距同步”不保证源动画正确。

内置示例可通过排布配置重新生成静态盘面；自定义格数同样参与采样率计算，例如 40 格与 45 RPM 对应 30 fps。


## 多圆环编辑

在“素材与校准”区域切换到“多圆环”。单盘面和多圆环会保留各自的素材配置，切换会暂停并回到起点。当前支持 1–4 圈，可添加、隐藏、删除和排序。图片仍仅保存在当前浏览器会话内，刷新后需重新选择。

每圈独立设置：

- 素材：内置示例或本地盘面图片；图片可单独校准圆心与半径。
- 排布：圆周格数、独立帧数、重复次数，满足格数=帧数×重复。
- 源圆环：从校准后的源盘片选取内外缘百分比。
- 目标圆环：将源圆环映射到完整盘面的指定内外缘；半径以盘片外缘为 100%。
- 相位：将整圈图案固定旋转指定角度，不建立独立于唱片的播放速度。

所有启用圆环先烘焙为一张静态纹理，再共同旋转和采样；没有单独播放各圈的角色。径向映射会改变图案在径向的比例，请通过预览检查细节。列表下方的圆环后绘制，重叠时覆盖上方。

“观察此圈”定位固定观察窗；“设为同步参考圈”决定自动采样率。编辑圈与观察圈、参考圈彼此独立。不同格数不保证同一相机下同时逐格匹配，每圈的“采样检查”会显示每次采样前进格数、本圈所需的匹配采样率与对应周期。隐藏或删除参考圈后，改用首个启用圈；所有圈隐藏时显示空状态。

默认三圈都使用 54 格，外圈 18 帧×3、中圈 9 帧×6、内圈 27 帧×2。在 33⅓ RPM、30 fps 下，同时逐格同步，动作周期分别为 0.6、0.3、0.9 秒。

## 交互设计指南

`/design-guide` 包含三组内嵌教学实验：同步与曝光（复用静态盘面和曝光积分）、循环接缝（正确循环与重复首帧对照）、圆周排布（旋转方向、帧序和局部朝向）。支持手动播放、暂停、重置与逐帧检查；接缝实验可点击缩略帧或拖动滑杆。所有演示默认暂停，离开视野或隐藏页面时停止播放，减少动态效果模式下保留逐帧操作。

参数试算与预览共用排布状态：在固定 54 / 40 格的观看组合里，独立帧数和重复次数可双向调整，同时更新盘面分组、30 fps 动作周期和上方采样演示。参数预览支持连续播放与逐帧检查。圆周姿态重排、分组边界、局部朝向和状态切换使用短过渡；相机采样与接缝姿态保持离散，减少动态效果模式禁用过渡。


每个圆环拥有独立的可展开卡片，可同时展开多圈。卡片收起时显示名称、范围、格数及启用状态；展开后在“素材与循环”“位置映射”“采样检查”间切换；源图范围与目标盘面位置分别编辑。重命名、排序和删除位于“管理此圈”。“观察此圈”只定位监视器，“采样检查”中的参考圈设置用于相机自动匹配，两者不随编辑选择暗中切换。展开、折叠和分组切换均保留图片与未应用草稿。

### CD 受控变速

在“唱片运动”中切换“CD 受控变速”。可配置起止读取半径（25–58 mm）、1× 线速度（1.2–1.4 m/s）、扫描时长、理想 CLV 跟随或电机加减速上限。应用参数、切换驱动或改变 CD 旋转方向都会暂停并重置到起点。终点半径保持不动，受限电机继续追踪至稳定；支持向内扫描与相同半径的恒速对照。初始电机已稳定，不模拟从静止启动。

目标 RPM = 60v / (2πr)。采用等螺距 CLV 扫描路径，因此半径平方随时间线性变化。默认用 20 秒加速演示读取过程，不代表真实整盘播放时长；电机采用可调的加减速限制教学模型，不模拟某款光驱的完整伺服系统。物理线速度范围参考 [ECMA-130 §11.4](https://ecma-international.org/wp-content/uploads/ECMA-130_2nd_edition_june_1996.pdf)。

CD 模型预计算 240 Hz 控制轨迹，以分段线性转速积分得到连续角度。相机采样和曝光积分始终读取这条轨迹，再旋转同一份静态盘面；暂停、逐帧、搓碟和浏览器帧率不会改变控制轨迹。相机保持固定帧率，“匹配起始转速”只计算初始匹配值；“匹配当前转速”以当前速度设置新的固定采样率，不持续追踪电机。转速曲线与读数展示当前已应用参数。

### 配置栏信息层级

侧栏使用 shadcn Scroll Area（Radix）覆盖式滚动条，仅滚动时显示，停止后 600ms 自动隐藏，不预留系统滚动条槽位。配置按三级组织：主分组为「运动与采样」「观察与检查」「素材与结构」，组内使用较轻的子标题，具体参数使用标签和值行。主分组标题无底色，使用 13px 主文字色和较强字重，与 11px 次要颜色子标题明确区分层级，随内容正常滚动，不设置吸顶或额外层级；主分组和子区块的分隔线横贯整个侧栏，区块内部的辅助分隔线保持左右等距缩进。

## 从零制作盘面的指南

设计指南按六个操作步骤组织：选动作、定帧数、画循环帧、排成圆盘、旋转采样检查、整理成品。每一步提供操作说明与可勾选的完成标准；目标、参数与自查进度保存在当前标签页，方便从工作台返回续做。源素材在绘图工具中制作，工作台用于导入与验证，不自动生成或重排用户的图片。

第 4 步可按当前参数下载 1200×1200 SVG 辅助模板，包含逆时针递增的源帧号、统一放置基准、朝向与内外缘。模板适用于顺时针播放，绘制完成后隐藏 guides 辅助组再导出 PNG。第 5、6 步可下载包含动作目标、排布和观看条件的设计单。公式、接缝错误对照、帧序演示和排错表按需展开，参数联动及动态过渡继续保留。
